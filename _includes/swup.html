{% comment %} Smooth in-page navigation via Swup (https://swup.js.org). Only #page-content is swapped between pages, so the masthead and sidebar DOM stay mounted (they never blink or reload). Links are preloaded on hover for a near-instant swap, covered by a short opacity fade (see _sass/layout/_swup.scss). Progressive enhancement: this is a module script, so legacy browsers skip it; if the CDN import fails, the catch leaves every link as a normal full-page load. Swup only initializes on pages that actually have the #page-content container (the shared masthead + sidebar shell), so sidebar-less layouts fall back too. {% endcomment %}
